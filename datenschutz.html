Datenschutz

Der Rechner läuft vollständig in deinem Browser. Er schickt nichts an einen Server, setzt keine Cookies und misst nichts.

Kurz gefasst

  • Was du eingibst, bleibt in deinem Browser. Es wird nirgendwohin übertragen.
  • Keine Cookies, kein Tracking, keine Reichweitenmessung, keine Einbindung von Dritten.
  • Die Schriften liegen auf demselben Server wie die Seite, nicht bei Google.
  • Beim Aufruf der Seite fällt beim Hoster GitHub eine Server-Protokollzeile mit deiner IP-Adresse an. Darauf hat der Betreiber dieser Seite keinen Zugriff.

Kontakt

Die Seite ist ein privates Hilfsprojekt ohne Anmeldung, ohne Konto und ohne Formular. Fragen zu ihr – auch solche zum Datenschutz – laufen über die Vorgänge im Quellcode-Verzeichnis: github.com/rorar/klein-rechner/issues.

Achtung: Was dort steht, ist für jeden lesbar und bleibt dauerhaft abrufbar. Schreib also nichts hinein, was niemanden sonst angeht.

Ein Datenschutzbeauftragter ist nicht bestellt; die Voraussetzungen des Art. 37 DSGVO liegen für ein Projekt dieser Größe nicht vor.

Was die Seite selbst tut

Deine Eingaben

Artikelpreis, Versandkosten, Zahlweg und die Schalter rechnet ausschließlich JavaScript in deinem Browser aus. Es gibt keine Schnittstelle, an die etwas geschickt würde, und keinen Server, der etwas entgegennähme. Lädst du die Seite neu oder schließt sie, sind die Eingaben weg.

Die Adresszeile

Der Rechner schreibt deinen Stand laufend in die Adresse, damit du sie weitergeben kannst – etwa ?preis=45,00&versand=5,49. Zwei Folgen: Die Beträge stehen im Verlauf deines Browsers, und wer einen solchen Link von dir bekommt, sieht die Beträge darin. Die Adresse wird dabei nicht abgerufen, sondern nur ersetzt; der Server erfährt davon nichts.

Kopieren, Teilen, Bild speichern

„Text kopieren“ und „Link kopieren“ schreiben in die Zwischenablage deines Geräts. „Als Bild speichern“ zeichnet den Beleg im Browser und legt eine PNG-Datei zum Herunterladen an. Auf Geräten mit Teilen-Funktion reicht „Teilen“ Text oder Bild an das System weiter, das dich dann fragt, wohin. Alle drei laufen nur, wenn du den Knopf drückst, und nur auf deinem Gerät. Wohin du das Ergebnis anschließend gibst, entscheidest du.

Kein Speicher, keine Cookies

Die Seite setzt keine Cookies und legt nichts in Local Storage oder Session Storage ab. Eine Einwilligung nach § 25 TDDG ist deshalb nicht nötig – es gibt nichts, wozu einzuwilligen wäre.

Einbindung in fremde Seiten

Der Rechner lässt sich von anderen Seiten einbinden und über postMessage befragen. Er antwortet dann nur dem Fenster, das gefragt hat, und nur mit dem Rechenergebnis. Gespeichert oder weitergegeben wird dabei nichts.

Was beim Aufruf anfällt

GitHub schreibt dazu selbst: Wird eine GitHub-Pages-Seite aufgerufen, wird die IP-Adresse des Besuchers zu Sicherheitszwecken protokolliert und gespeichert – unabhängig davon, ob er bei GitHub angemeldet ist oder nicht (Dokumentation zu GitHub Pages).

Dein Browser sendet dabei, was das Übertragungsverfahren vorsieht: die abgerufene Adresse, die zuvor besuchte Seite (Referer) und Angaben zu Browser und Betriebssystem. Der Server selbst hält üblicherweise Datum und Uhrzeit der Anfrage, den Status der Antwort und die übertragene Datenmenge fest. Ausdrücklich dokumentiert nennt GitHub nur die IP-Adresse; das Übrige ist das, was jeder Webserver protokolliert. Wie lange GitHub das aufbewahrt, gibt GitHub nicht an – hier wird deshalb keine Frist behauptet.

Der Betreiber dieser Seite hat auf diese Protokolle keinen Zugriff und bekommt von ihnen nichts zu sehen. Eine Auswertung findet nicht statt, weil es nichts auszuwerten gibt.

Übermittlung in die USA

Dabei werden Daten in die USA übermittelt. GitHub stützt solche Übermittlungen nach eigener Angabe auf die Standardvertragsklauseln der Europäischen Kommission (Durchführungsbeschluss 2021/914) und ist zusätzlich unter dem EU-U.S. Data Privacy Framework zertifiziert. Beides steht in der Datenschutzerklärung von GitHub, die weiter unten verlinkt ist; den Wortlaut der Klauseln führt GitHub in seinem Data Protection Agreement.

Wie GitHub mit Daten umgeht und welche Rechte du dort hast, steht in der GitHub-Datenschutzerklärung. Den Datenschutzbeauftragten von GitHub erreichst du unter dpo@github.com, Anliegen zum Datenschutz nimmt GitHub außerdem über ein eigenes Formular entgegen.

Kein Auftragsverarbeitungsvertrag

Mit GitHub besteht kein Vertrag zur Auftragsverarbeitung nach Art. 28 DSGVO. Das Bayerische Landesamt für Datenschutzaufsicht hält das Hosten rein statischer Seiten ohne Nutzer-Verfolgung nicht für Auftragsverarbeitung: die kurzfristige Speicherung der IP-Adresse sei „noch der TK-Zugangsvermittlung des Website-Hosters nach dem TKG zuzurechnen“ und diene in erster Linie Sicherheitszwecken des Hosters (Auslegungshilfe des BayLDA). Diese Seite ist genau so ein Fall: statisch, ohne Formular, ohne Konto, ohne Messung. Die Auslegungshilfe stammt von 2019 und beruft sich auf das damalige TKG; seither hat sich die Einordnung von Hosting-Diensten verschoben, und ein Teil der Praxis schließt heute auch für statische Seiten einen solchen Vertrag.

Links zu anderen Anbietern

Die Seite lädt nichts von fremden Servern nach – keine Schriften, keine Skripte, keine Bilder, keine Karten. Sie verlinkt aber auf andere Anbieter, etwa auf das Hilfe-Center von Kleinanzeigen und auf GitHub. Erst wenn du so einen Link anklickst, erfährt der jeweilige Anbieter deine IP-Adresse. Was er damit tut, steht in seiner eigenen Datenschutzerklärung.
